This editor is part of the test version. Anyone who has its address can use it, so every post waits for approval. A team member approves it in the shared sheet, and the site then shows it within about 2 minutes.

Write the text in Markdown, plain text with a few marks:

- `## Heading` makes a heading.
- `**bold**` makes bold text.
- `[link text](https://example.org)` makes a link.
- An empty line starts a new paragraph.
